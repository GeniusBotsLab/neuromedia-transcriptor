## English

**NeuroMedia Transcriptor** turns video and audio into an organized, searchable workspace. Import local media or download from supported sources, create transcripts on your computer with timestamps and speaker labels, then use an AI provider you choose to summarize, translate, clean up, or query the transcript.

### What it does

- Creates searchable local transcripts with timestamps and speaker labels.
- Produces concise AI summaries, translations, FAQs, notes, and answers from your transcript.
- Imports local audio/video and supports downloads from sites supported by its download engine.
- Exports transcript text and Markdown; manages media, metadata, formats, and download queues.
- Lets you choose an AI provider or compatible local endpoint. AI requests are sent only to the provider you configure.

### Start locally

```bash
pnpm install
pnpm run start:web
```

For Docker:

```bash
docker compose up -d --build
```

Use media only where you have the necessary rights and comply with the terms of the source platform.
